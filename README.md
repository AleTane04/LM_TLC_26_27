## LM TLC - Materiali e Appunti

Questo repository raccoglie il materiale didattico, gli appunti e la documentazione del corso.

### Struttura del Repository

* **`ELSD/`**: Raccolta completa delle lezioni del modulo ELSD (da ELSD 1 a ELSD 14). 
  * *Nota sui file:* All'interno di ciascun file PDF è indicata la data specifica in cui si è tenuta la rispettiva lezione.
* **`CD/`**: Raccolta delle lezioni del modulo CD (da CD 1 a CD 8 e CD 23), ci sono lezioni mancanti in quanto sono le lezioni dei pdf di Gelli
